# Preserved research prototype

This directory is archival and intentionally not importable by `aims_berry`.

- `prototype/` contains the original scripts exactly as they existed at the repository
  root before the modular refactor.
- `results/` contains the original generated trajectory trees, plots, and text output.

See [`docs/migration.md`](../docs/migration.md) for the concept-to-API map. Git history
was not rewritten, so earlier revisions retain their original layout.
